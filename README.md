# DingMao 个人作品集

黑色背景响应式静态网站，无需安装依赖。页面顺序：首屏 → 基本信息 → 作品 → 关于我，附联系区与页脚。

## 打开

直接双击 `index.html` 即可。也可以在当前文件夹执行 `node server.cjs`，访问 http://127.0.0.1:4173 。

## 后续填充

- `index.html`：姓名、基本信息、自我介绍、经历和页脚文案。
- `content.js`：作品标题、分类、年份、图片列表；可添加 `description` 项目描述。`email` 填入真实邮箱后自动显示邮件联系链接。
- `styles.css`：配色、尺寸、响应式与动效。主色由顶部的 `--accent` 控制。
- `assets/hero.webp`：用户提供的首屏图片的压缩副本，完整保留画面。
- `assets/1.webp` 至 `14.webp`：本地原图的压缩副本。根目录原始 PNG 未修改。

作品标题和分类是临时整理，年份为占位值，职业文案与经历需确认替换。最后一个作品卡片专门预留给 UI / 产品项目。所有作品均可点击打开预览；分类、导航、手机菜单、返回顶部、Esc 关闭预览均可用。支持减少动态效果的系统偏好。

## 环形作品画廊

作品区以用户提供的 Cipher 截图为视觉依据，采用环形错落布局。每张海报独立呈现，悬停或键盘聚焦时置顶放大并显示项目信息；左右按钮转动排列，可切换平铺视图。分类沿用 content.js 的项目配置，点击海报会优先预览当前图片。gallery.css 管理新版作品区样式。参考站首页本次仅返回加载界面，实际动态行为未能验证。
